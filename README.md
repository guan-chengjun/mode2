# 燃煤火电站 3D 交互式仿真系统

基于 **Three.js** 的燃煤火电站全流程 3D 交互式仿真项目。采用多文件模块化结构，全部设备模型由代码参数化生成，**无外部模型文件依赖、可完全离线运行**，同时预留 glTF 外部模型替换接口。

## 功能特性

- **全套核心设备建模**：锅炉本体、燃烧系统（磨煤机+四角燃烧器）、水冷壁、过热器、汽轮机（高/中/低压缸+转子）、发电机、凝汽器、循环冷却水系统（双曲线冷却塔）、引送风机、烟道（含空预器）、SCR 脱硝、电除尘、湿法脱硫、烟囱、输煤栈桥、煤仓，共 16 类设备。
- **透视剖切**：X / Y / Z 三个正交剖切平面，滑块实时控制剖切位置，可"切开"任意厂房与设备。
- **外壳独立显隐**：每台设备的外壳可单独隐藏，查看内部结构（炉膛水冷壁、汽轮机转子、SCR 催化剂层、电除尘极板、脱硫塔喷淋层、煤仓煤位等）。
- **完整工艺流程仿真**：
  - 上煤：煤场 → 输煤栈桥 → 煤仓 → 磨煤机 → 燃烧器（煤流粒子）
  - 燃烧：炉膛火焰（加色混合粒子 + 火光闪烁点光源）
  - 汽水循环：锅炉 → 主蒸汽 → 汽轮机 → 凝汽器 → 给水回炉（红/蓝粒子流）
  - 发电：汽轮机与发电机转子联动旋转
  - 烟气净化：炉膛 → SCR 脱硝 → 空预器 → 电除尘 → 引风机 → 脱硫塔 → 烟囱（灰色烟气流 + 烟囱羽流）
  - 水循环冷却：冷却塔 ↔ 凝汽器闭环水流 + 冷却塔顶部水蒸气羽流
- **自由视角**：鼠标旋转 / 缩放 / 平移，点击设备自动聚焦。
- **设备信息**：点击场景模型或左侧列表，显示设备名称与工艺说明。
- **工况控制**：运行/暂停、仿真速度（0.2~3 倍）、机组负荷（0~100%，联动流量、火焰强度、转速）。

## 部署运行

### 环境要求

- Node.js ≥ 18（仅开发/构建需要；运行产物为纯静态文件）
- 支持 WebGL 的现代浏览器（Chrome / Edge / Firefox / Safari）

### 开发模式（推荐）

```bash
npm install      # 安装依赖
npm run dev      # 启动开发服务器
```

终端会输出访问地址（默认 `http://localhost:5173`），浏览器打开即可。支持热更新。

### 生产部署

```bash
npm run build    # 构建到 dist/
npm run preview  # 本地预览构建产物（默认 http://localhost:4173）
```

`dist/` 目录为纯静态文件，可部署到任意静态服务器（Nginx、Apache、IIS、GitHub Pages、对象存储等）。Nginx 示例：

```nginx
server {
    listen 80;
    root /var/www/power-plant/dist;
    index index.html;
}
```

> 注意：项目使用 ES 模块，**不能直接双击 index.html 以 file:// 打开**，必须通过 HTTP 服务访问。

## 交互操作说明

### 视角操作

| 操作 | 效果 |
|---|---|
| 鼠标左键拖拽 | 旋转视角 |
| 鼠标右键拖拽 | 平移视角 |
| 滚轮 | 缩放 |
| 左键单击设备 | 选中设备，相机自动聚焦，右侧显示工艺说明 |
| 「复位视角」按钮 | 回到全厂鸟瞰视角 |

### 左侧面板（设备列表）

- 点击**设备名称**：相机聚焦该设备并显示工艺说明。
- 勾选/取消**「外壳」**：单独显示/隐藏该设备外壳，查看内部结构（如水冷壁管屏、汽轮机转子、SCR 催化剂层、电除尘极板、脱硫塔喷淋层、煤仓煤位、烟囱内筒等）。

### 底部控制条

**仿真工况控制**

| 控件 | 说明 |
|---|---|
| ⏸ 暂停 / ▶ 运行 | 暂停/恢复整个仿真（流体、火焰、转子） |
| 速度 | 仿真时间倍率 0.2 ~ 3.0 |
| 负荷 | 机组负荷 0~100%。联动：粒子流速、火焰大小与火光、烟囱/冷却塔羽流量、汽轮机与发电机转速 |

**剖切控制**

- 勾选 X / Y / Z 启用对应方向的剖切平面，拖动滑块改变剖切位置：
  - **X**：沿东西向切开（保留 ≤ 滑块值的一侧），适合剖开锅炉房、汽机房看内部。
  - **Y**：水平剖切（保留滑块高度以下部分），适合去掉厂房顶部俯视内部。
  - **Z**：沿南北向切开，适合剖开尾部烟道与环保设备。
- 三个平面可任意组合；取消勾选即恢复完整模型。

**流系显示开关**

- **煤流**：煤场→煤仓→磨煤机→燃烧器的煤粉粒子。
- **风烟**：送风气流 + 炉膛→烟囱的烟气流。
- **汽水**：主蒸汽/再热蒸汽（红橙色）+ 给水（蓝色）。
- **冷却水**：冷却塔↔凝汽器循环水（青色闭环）。
- **火焰/羽流**：炉膛火焰、烟囱羽流、冷却塔水蒸气羽流。

## 仿真流程一览（与画面对应）

1. **上煤**：煤堆 → 输煤栈桥（灰色粒子上行）→ 煤仓 → 磨煤机 → 四角燃烧器。
2. **燃烧**：炉膛内火焰粒子翻滚，火光随负荷闪烁；送风机送入助燃风（浅蓝粒子）。
3. **产汽**：给水（蓝）进入锅炉，主蒸汽（红橙）从汽包送往汽轮机高压缸，再热蒸汽循环回炉。
4. **发电**：蒸汽推动汽轮机转子（隐藏汽缸可见旋转），同轴带动发电机。
5. **冷凝**：排汽在凝汽器被循环水冷凝，凝结水回送锅炉完成汽水循环。
6. **烟气净化**：烟气（灰）依次经 SCR 脱硝、空预器、电除尘、引风机、脱硫塔，最后从烟囱排出（白色羽流）。
7. **冷却**：循环水（青）在冷却塔与凝汽器间闭环流动，塔顶飘出水蒸气羽流。

## 扩展指南

### 替换为 glTF 外部模型

设备均为独立 Group，可整体替换为下载的 glTF 模型（如 Sketchfab 上 CC 许可的火电设备模型）：

```js
import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';
const gltf = await new GLTFLoader().loadAsync('/assets/models/boiler.glb');
// 在 equipment/boiler.js 中用 gltf.scene 替换参数化外壳，
// 并对需要隐藏的网格设置 userData.shell = true 即可接入外壳显隐与剖切。
```

注意：外部模型需自行确认授权；剖切功能对所有材质自动生效（全局剖切平面），外壳显隐需模型网格可分离。

### 调整布局 / 新增设备

1. 在 `src/equipment/` 新建或修改建模文件，返回 `{ id, group, focus, dist }`。
2. 在 `src/data/info.js` 中补充对应 `id` 的名称与工艺说明。
3. 在 `src/systems/flows.js` 中添加对应的 `Flow` 路径即可接入工艺动画。

## 常见问题

- **页面空白**：确认通过 HTTP 访问（`npm run dev`），而非直接双击 HTML；查看浏览器控制台报错。
- **剖切无效**：确认勾选了对应方向的复选框；剖切平面默认在无穷远处。
- **帧率低**：在 `src/core/stage.js` 中降低 `setPixelRatio` 上限或关闭阴影。
